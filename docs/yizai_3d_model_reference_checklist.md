# 亿仔 3D 模型参考图清单

以下图片用于混元 AI 生成 3D 模型和后续 3D 制作，不是直接进入游戏的最终资源。

## 必备参考图

1. 亿仔原始 IP 正面参考图。
2. 亿仔童话勇者正面图。
3. 亿仔童话勇者侧面图。
4. 亿仔童话勇者背面图。
5. 亿仔童话勇者 45 度图。
6. 头部五官特写。
7. 帽子 `MAEE` 特写。
8. 服装材质卡。
9. 短剑、腰带、披风、靴子配件图。
10. 动作参考图：attack、skill、ultimate、hurt。

## 参考图检查点

- 白熊主体明确。
- 橙黄色口鼻区明确。
- 黑色大鼻子明确。
- 粗眉毛明确。
- 头部装饰正面 `MAEE` 清晰、未遮挡、未镜像。
- 蓝金勇者服、披风、腰带、短剑、靴子能被单独识别。
- 右朝向动作参考能看清手、剑、脚底基准线和身体重心。
- 所有参考图避免过度裁切帽子、披风、剑和特效区域。
